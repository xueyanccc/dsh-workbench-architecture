# DSH 工作台技术框架

这是「工作台」（DSH Desktop Workbench）的架构与从零搭建手册，按本机实装版本记录。

| 项 | 值 |
|---|---|
| 内核 | `@deepseek-ai/dsh` 0.2.2-rc.3 |
| 外壳 | `dsh-workbench` 0.2.2-rc.3（Electron 主进程 + 原生渲染层） |
| Electron | 43.0.0（运行时）；devDependency 43.4.0 |
| Node | v24.22.0 |
| 系统 | Windows 10/11 x64 |
| 插件档位 | `profiles/web`，20 个 bundle |

## 一句话结构

**Electron 外壳负责「窗口 + 面板 + 场景切换」，DSH 内核负责「会话 + 模型 + 工具 + 插件」，`.dsh` 目录负责「配置与记忆」，工作区负责「产物」。**

## 三条设计原则

1. **一层只做一件事**：外壳不碰模型，内核不碰像素，记忆不碰业务产物。
2. **场景即隔离**：一个场景 = 一份 JSON + 一个会话 + 一份私有记忆 + 一个工作区目录；跨场景只通过共享记忆通信。
3. **可回滚**：所有脚本化操作（建会话、换场景、改记忆）都要能 `check` 出差异，改内核前先备份到 `外壳/data/backups`。

## 脱敏约定

本文档面向公开仓库，本机与账号信息全部替换为占位符：

| 占位符 | 含义 |
|---|---|
| `<WORKBENCH>` | 工作台根目录 |
| `<DSH_HOME>` | 内核配置与记忆根 |
| `<USER_HOME>` | 当前用户主目录 |
| `<NODE_HOME>` | Node 安装目录 |
| `<GITHUB_USER>` | 仓库属主 |
| `<GUI_PORT>` / `<GATEWAY_PORT>` / `<SITE_PORT>` | 本机服务端口 |
| `session-<ID>` | 会话标识 |
| 某 Electron 商业应用 | 被分析过的具体软件（不公开） |

提交前自检：仓库内不得出现真实绝对路径、用户名、账号、手机号、密钥、样本名与样本哈希。
